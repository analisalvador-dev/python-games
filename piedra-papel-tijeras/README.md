# Piedra, Papel o Tijeras

Juego de consola clásico de piedra, papel o tijeras contra la computadora, con opción de jugar varias rondas seguidas.

## Cómo jugar

1. Ejecuta el archivo:
   python main.py
2. Escribe tu elección: piedra, papel o tijera
3. La computadora elige al azar y se muestra el resultado
4. Puedes jugar otra ronda escribiendo s, o salir con cualquier otra tecla

## Tecnologías

- Python 3
- Módulo random

## Lo que uso

- Estructuras condicionales (if/elif/else)
- Bucles (while)
- Comparación de lógica de juego
