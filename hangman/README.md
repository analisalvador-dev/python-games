# Hangman (Ahorcado)

Juego del ahorcado en consola. La compu elige una palabra al azar y el jugador tiene 6 intentos para adivinarla, letra por letra.

## Cómo jugar

1. Corre el archivo:
   python main.py

2. Escribe una letra y presiona Enter.
3. Si la letra está en la palabra, se revela en su lugar. Si no está, pierdes un intento.
4. Ganas si adivinas toda la palabra antes de quedarte sin intentos.

## Tecnologías

- Python 3
